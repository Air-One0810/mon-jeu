# DOCTRINE DE GAME FEEL & JUICE (COMMERCIALISATION)

## 1. Philosophie du Feedback (L'Impact)
- Un jeu de cartes ne doit pas être une simple calculatrice Excel. Chaque action doit générer un retour clair pour l'utilisateur.
- Anticiper l'intégration du "juice" (animations, feedbacks textuels dynamiques, variations de rythme).

## 2. Traduction dans le Prototype
- Même dans un prototype console/Python, les logs de combat doivent être théâtralisés (ex: utiliser des émojis pour les éléments, espacer les actions clés, créer un sentiment de puissance lors des combos).
- Chaque modification de règle par une "Identité" doit s'accompagner d'un message UI fort pour que le joueur ressente l'altération du système.

## 3. PROTOCOLE SYSTÉMATIQUE DE PLAYTEST (LOG ANALYSIS)
- Je fournis le journal complet de mes logs à chaque fin de run. C'est notre outil principal d'équilibrage.
- Tu dois analyser ces logs sous trois angles : 
  1. La courbe de puissance (Le Power Trip était-il présent ? Les cartes Épiques/Légendaires ont-elles fait basculer la run ?).
  2. La validité mathématique (Pas de bugs de calcul, respect des Dégâts Effectifs).
  3. Le rythme (Est-ce qu'on a évité les combats "Excel" trop longs et ennuyeux ?).
